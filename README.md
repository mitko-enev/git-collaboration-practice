# git-collaboration-practice
A practice repository for learning Git and GitHub collaboration workflows including branches, pull requests, code reviews, and merge conflict resolution.

## objectives

- Practice branching strategies
- Create meaningful commits
- Open and review pull requests
- Resolve merge conflicts
- Collaborate in a team environment

## project-structure

- `/src` - Application source files
- `/docs` - Documentation
- `/profiles` - Contributor profiles

## workflow-rules

1. Do not push directly to `main`
2. Create a feature branch
3. Open a Pull Request
4. Request review
5. Merge after approval
